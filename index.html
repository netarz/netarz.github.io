NetArz & Gisoo open source

NetArz sells foreign digital services in Toman. Gisoo is its Persian AI app with an OpenAI-compatible API. These are the open-source pieces around them.

AI (Gisoo)

gisoo-python

Python helper: the official OpenAI client pointed at Gisoo, plus a model lister.

RepoDocs

gisoo-js

Node/ESM helper with TypeScript types: an OpenAI client for Gisoo and a model lister.

RepoDocs

gisoo

Overview and code examples for the Gisoo API, including Claude Code and the Anthropic SDK.

Repogisoo.pro

ai-api-examples

Examples for the NetArz AI API: streaming, tools, embeddings, LangChain, n8n, Telegram bot.

RepoProduct

netarz-ai-wordpress

WordPress/WooCommerce plugin: AI support chat with human handoff, tickets and writing tools (GPL).

Repogisoo.pro/wordpress

netarz-ai-whmcs

WHMCS addon: AI live chat and AI ticket replies.

RepoProduct

gisoo-trader

A crypto trading bot (MIT) that can use Gisoo models. Not financial advice; trading can lose money.

Repogisoo.pro/trader

پروژه‌های متن‌باز نِت اَرز و گیسو

نِت اَرز مرکز خرید سرویس‌های خارجی با تومان است و گیسو اپ هوش مصنوعی فارسی آن با وب‌سرویس سازگار با OpenAI. این‌ها بخش‌های متن‌بازِ پیرامون آن‌هاست.

هوش مصنوعی (گیسو)

gisoo-python

کتابخانهٔ کوچک پایتون: کلاینت رسمی OpenAI که به گیسو وصل شده، به‌همراه فهرست مدل‌ها.

مخزنمستندات

gisoo-js

کتابخانهٔ Node (ESM) با تایپ‌های TypeScript: کلاینت OpenAI برای گیسو و فهرست مدل‌ها.

مخزنمستندات

gisoo

معرفی و نمونه‌کد وب‌سرویس گیسو، از جمله Claude Code و کتابخانهٔ Anthropic.

مخزنgisoo.pro

ai-api-examples

نمونه‌کد وب‌سرویس هوش مصنوعی نِت اَرز: استریم، ابزارها، امبدینگ، LangChain، n8n و ربات تلگرام.

مخزنمعرفی

netarz-ai-wordpress

افزونهٔ وردپرس و ووکامرس: چت پشتیبانی هوشمند با سپردن به همکار، تیکت و ابزار نوشتن (GPL).

مخزنgisoo.pro/wordpress

netarz-ai-whmcs

افزونهٔ WHMCS: چت آنلاین و پاسخ تیکت با هوش مصنوعی.
